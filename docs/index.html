01 / The workflow

A clear path through
a complex recording.

Inspect the signal before you commit to settings. Teach the classifier with your own examples, then review its decisions at the level of individual spikes.

01 — PREVIEW

See what gets filtered.

Load a recording, name the nerves, and preview artifact exclusions, bandpass filtering, thresholds, and candidate peaks.

02 — SORT

Choose your approach.

Accept detections for a single unit, train a waveform classifier, or learn waveform and timing relationships with a context-aware model.

03 — REFINE

Make the final call.

Browse raw or filtered traces. Add missed spikes, remove false positives, relabel events, and undo or redo your changes.

04 — EXPORT

Take your data further.

Save a self-contained review and export accepted spikes as a CSV for each sorted nerve, alongside settings and edit history.

02 / Sorting methods

The right method
for each channel.

A clean single-unit channel and a mixed nerve recording need different tools. Choose the method per channel and keep the same review workflow.

Single-unit channels

Detection only

Assign a unit label, such as PD, and accept detected candidates without training a classifier. Thresholds and artifact exclusions still apply.

Waveform information

Waveform classifier

Label examples of neurons and noise, then train using waveform features. Compatible saved models can be reused with matching preprocessing and recording conditions.

Waveform + timing

Context-aware classifier

Use waveform and temporal information. Optionally learn timing relative to an accepted, labeled unit on a different channel in the current review.

03 / Get started

Your first recording
starts here.

Install Python first, download the repository ZIP, and extract it. Python 3.11 or 3.12 is recommended. The first launcher run needs internet access to install dependencies.

Launch on macOS

  1. Extract the downloaded ZIP.
  2. Double-click Launch Lobsort.command.
  3. Let the launcher create its environment and install dependencies.
# If Finder opens the launcher as text,
# open Terminal in the extracted folder:
bash "Launch Lobsort.command"

Try it before loading your data.

Choose File → Open demo recording for deterministic synthetic signals. Explore the preview and review controls without needing a recording file.

Then work through your recording.

Load an SMR or ABF file → enter the animal ID and name channels → preview and apply filtering → detect candidates → label and classify (or accept single-unit detections) → review → save and export.

04 / Save your decisions

Curated spikes.
A traceable workflow.

A .lobsort review stores signals, candidate decisions, settings, and edit history. Reopen it without the original recording to continue reviewing.

With an animal ID, exports are grouped into an animal-named folder. Each sorted nerve gets its own accepted-spike CSV; the details folder preserves candidates and review provenance.

Save periodically. Final review edits are not automatically saved after every click; training labels save separately.

A few things to know

Before you dive in.

Which recording formats are supported?

SMR and ABF, where Neo supports the specific format and version. Select a segment if the file contains more than one. SMRX requires a separate CED reader and is not supported in this release.

How many labels do I need to train?

Classifiers require at least three examples per class in at least two selected classes to start training. Larger, representative sets are preferable: label throughout the recording and include noise. Detection-only sorting needs no training labels.

How does timing from another channel work?

First obtain accepted spikes for a labeled reference unit, such as PD. On the target channel, enable “Learn timing from a labeled unit in this review,” select that reference channel and unit, then train a context-aware classifier. At least three accepted reference events are required. Reference timings are frozen for that run; retrain or classify again after reference edits.

Is the download a standalone installer?

No. It is the current repository source ZIP, including launchers. Python 3.10 or newer is required. A running copy does not update itself; download updated code to get new features. Save an unfinished recording as a .lobsort review before switching copies.

How should I interpret classifier confidence?

Confidence is a model score, not a guaranteed biological accuracy rate. Initial validation used synthetic recordings; real-recording input and biological sorting accuracy remain unvalidated. Review results carefully. Use an independent reference when evaluating timing-based models.

Why does GitHub ask me to sign in?

The Lobsort repository is currently private. The source ZIP and repository documentation require a GitHub account with repository access. If you cannot open the repository, request access from the maintainer.

Can I import results from the notebook?

Yes. Use File → Import sorted spike CSV. The CSV needs time_seconds, and manual_label or predicted_label is used when present. Compatible saved waveform joblib models are also supported. Only load trusted model files.
